# Contributing to Skaldryne

Thank you for helping improve Skaldryne.

We welcome bug reports, documentation improvements, feature proposals, integrations, tests, and code contributions.

## Contributor agreement

**External code or documentation contributions should not be merged until the project's final Contributor License Agreement (CLA) has been approved and the contributor has accepted it.**

See `CLA.md`.

Contributors should retain ownership of their work while granting Skaldryne sufficient rights to distribute, sublicense, and commercially license accepted contributions.

## Pull requests

Keep pull requests focused on a single logical change. Where appropriate:

- include tests;
- update documentation;
- describe architectural impact;
- identify new third-party dependencies and their licenses;
- disclose generated or substantially AI-assisted code where relevant to provenance review.

## AI-assisted contributions

AI-assisted development is permitted, but contributors remain responsible for submitted work. Do not submit material you do not have sufficient rights to contribute. Review generated code for security, correctness, licensing concerns, and inappropriate reproduction of third-party source.

## Third-party code

Do not copy third-party source into Skaldryne without license review. New dependencies must be compatible with Skaldryne's distribution and commercial-licensing model.

## Security

Do not publicly disclose exploitable vulnerabilities before following the process in `SECURITY.md`.
