# Skaldryne Legal Setup Checklist

Before public launch:

- [ ] Choose the legal copyright holder.
- [ ] Replace `[COPYRIGHT HOLDER]` in `LICENSE` and `NOTICE`.
- [ ] Add licensing, commercial, security, trademark, and CLA contact addresses.
- [ ] Have qualified software/IP counsel review the complete licensing structure.
- [ ] Replace the draft `CLA.md` with counsel-approved Individual/Corporate CLA terms or a CLA service.
- [ ] Decide whether to register SKALDRYNE as a trademark.
- [ ] Confirm domain, GitHub organization, and package namespace ownership.
- [ ] Configure dependency/license scanning in CI.
- [ ] Establish third-party dependency approval rules.
- [ ] Establish a private vulnerability reporting mechanism.
- [ ] Ensure repository and website consistently call the project **source-available**, not OSI open source.
- [ ] Document which directories/components, if any, use different licenses.
- [ ] Review hosted-service Terms of Service and Privacy Policy separately before operating a cloud service.

## Important

This scaffold is a project-planning package, not legal advice. The official PolyForm license text is included unmodified except for the project-specific `Required Notice:` line permitted by its notice mechanism. Supporting project documents should be reviewed by qualified counsel before commercial reliance.
