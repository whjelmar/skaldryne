# Security Policy

## Reporting a vulnerability

Please do not disclose an exploitable security vulnerability in a public issue before the project has had an opportunity to investigate it.

Report suspected vulnerabilities privately to:

**[SECURITY EMAIL OR PRIVATE REPORTING URL]**

Include, when possible:

- affected version or commit;
- component;
- reproduction steps;
- expected impact;
- proof-of-concept details;
- suggested remediation, if known.

The project will acknowledge reports and coordinate disclosure based on severity and available maintainer capacity.

Do not include campaign data, credentials, tokens, personal information, or other sensitive material beyond what is necessary to demonstrate the issue.
